# 테스트 및 QA 가이드

이 문서는 로컬 개인정보 마스킹 프로그램의 자동 테스트와 수동 점검 절차를 정리합니다. 샘플 데이터는 모두 테스트용 가상 개인정보이며, 실제 개인정보를 테스트 파일명이나 로그에 넣지 마세요.

## 1. 테스트 준비

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
cd "C:\Users\덕유중\Documents\DATA MASKING\privacy_masker"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

OCR 기능까지 확인하려면 Windows에 Tesseract OCR을 별도로 설치하고 `tesseract.exe`가 PATH에 잡혀 있어야 합니다. Tesseract가 없으면 OCR 관련 실제 인식 테스트는 건너뛰고, "설치 필요" 오류 메시지 확인만 수행합니다.

## 2. 샘플 파일 생성

```powershell
python tools\create_sample_files.py
```

예상 결과:

- `sample_files\sample_pii.xlsx`
- `sample_files\sample_pii.docx`
- `sample_files\sample_pii_text.pdf`
- `sample_files\sample_pii_scan_like.pdf`
- `sample_files\sample_pii.hwpx`
- `sample_files\unsupported.txt`
- `sample_files\corrupted.pdf`
- `sample_files\corrupted.hwpx`
- 선택 라이브러리가 없으면 해당 형식은 skip 메시지가 표시됩니다.

## 3. 자동 테스트

```powershell
pytest tests
```

중점 확인 항목:

- XLSX, DOCX, PDF, HWPX 탐지 및 저장
- 선택된 항목만 마스킹
- 사용자가 수정한 `masked_text` 반영
- 원본 파일 해시 불변
- CSV 로그에 `original_text`, `masked_text`, 탐지된 개인정보 원문 미저장
- HWP 미지원 안내
- OCR/Tesseract 미설치 시 명확한 오류 처리

## 5. 알려진 테스트 한계

- 스캔 PDF OCR은 인식 누락과 오탐 가능성이 있으므로 자동 테스트만으로 충분하지 않습니다.
- DOCX는 첫 버전에서 `paragraph.text` 기반 치환을 사용하므로 일부 run 서식이 단순화될 수 있습니다.
- HWPX는 ZIP 내부 XML 텍스트 중심 처리이며, 이미지/첨부/복잡한 메타데이터 안의 개인정보를 전부 보장하지 않습니다.
- 구형 HWP는 안정 지원 대상이 아니므로 HWPX 변환 후 처리해야 합니다.
- CSV 로그에는 개인정보 원문을 저장하지 않지만, 파일명 자체에 개인정보가 있으면 파일명이 로그에 남을 수 있습니다. 테스트 파일명과 실제 운영 파일명에 개인정보를 넣지 않는 정책이 필요합니다.
